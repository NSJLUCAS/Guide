# Archived upstream installer

`install-hub.sh` preserves the complete bytes of the pre-Guide installer, including
the existing early exit that disables upstream installation and updates. It is an
archived compatibility reference, not a supported Guide installer. Do not run it
or distribute it as a Guide release asset.

The Monitor names, URLs, service paths, and updater implementation in this archive
record upstream provenance only. Guide's active `../../install-hub.sh` refuses
installation and updates; build Guide from this project's source instead.
