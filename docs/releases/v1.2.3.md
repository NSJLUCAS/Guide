## 新增

- **页脚动画开关**：后台「设置 → 导航外观」新增「页脚动画」开关，切换后立即生效。关掉后导航页不再显示小人，左下角的 GitHub 入口保留。已有站点升级后默认开启。
- **新图标**：网站图标换成两个向前的箭头，导航页和后台的顶栏也显示这个图标。浏览器标签页上的图标会跟随系统的深浅色变化。

## 升级方式

先看完上面的内容，决定更新的话，在服务器终端运行：

```bash
sudo guide-update
```

更新前会自动备份数据库，失败会自动回滚。只想确认版本、不更新：

```bash
sudo guide-update --check
```
