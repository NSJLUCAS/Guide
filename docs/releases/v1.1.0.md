# Guide v1.1.0 Release Notes — 草稿，尚未发布

本文件仅供正式发版前审核，不代表 v1.1.0 已发布。当前已发布正式版本仍是 v1.0.0；以下下载与安装命令只有 v1.1.0 正式 Release 发布后可用。

## 新功能

- 官方 `install-guide.sh` 一键安装，以及 `/usr/local/sbin/guide-update` 一键升级。
- `guide-update --check` 只读检查更新；使用 NSJLUCAS/Guide 的 latest 正式版，禁止自动降级。
- 自动 SHA-256 校验归档和安装器，下载完整、归档白名单和版本校验成功后才停止旧服务。
- 自动备份真实 DB/WAL/SHM 与旧 binary；新版启动失败整体回滚，保留失败状态和原备份。
- 安装器校验 SHA 后自更新；保留已有 systemd 配置、数据和认证信息。

## 支持的平台

Linux x86_64 GNU/glibc + 可运行的 systemd；要求 root、Python 3.8+、curl 和安装说明列出的系统工具。GNU 二进制在 Ubuntu 22.04 构建，运行环境须有兼容的 glibc。新实例默认监听 `127.0.0.1:28080`，通过自有 HTTPS 反向代理访问。

## 首次安装

确认机器上没有旧 Guide 实例，在空下载目录中执行。校验失败立即停止：

```sh
curl -fsSL https://github.com/NSJLUCAS/Guide/releases/download/v1.1.0/install-guide.sh -o install-guide.sh &&
curl -fsSL https://github.com/NSJLUCAS/Guide/releases/download/v1.1.0/sha256sums.txt -o sha256sums.txt &&
grep -E '^[[:xdigit:]]{64}  install-guide[.]sh$' sha256sums.txt > install-guide.sh.sha256 &&
sha256sum --check install-guide.sh.sha256 &&
sudo sh ./install-guide.sh
```

标准路径为 `/opt/guide/guide-hub`、`/var/lib/guide/guide.db`、`guide.service` 和 `/usr/local/sbin/guide-update`。首次安装生成独立随机应急密码，在终端显示；首次登录后台后立即修改。

## 从 v1.0.0 升级

v1.0.0 没有官方 updater，但已有受支持 `guide.service` 可直接接入。先核对 unit/drop-in：直接执行绝对 `guide-hub`，明确绝对 `--db` 和 `--listen`，原 DB 存在，路径无不支持的映射。自定义 binary/DB/listen/User/WorkingDirectory 等配置可以保留。

确认旧部署满足条件后，在空下载目录中只下载、校验并检查；不要执行上面的首次安装代码块：

```sh
curl -fsSL https://github.com/NSJLUCAS/Guide/releases/download/v1.1.0/install-guide.sh -o install-guide.sh &&
curl -fsSL https://github.com/NSJLUCAS/Guide/releases/download/v1.1.0/sha256sums.txt -o sha256sums.txt &&
grep -E '^[[:xdigit:]]{64}  install-guide[.]sh$' sha256sums.txt > install-guide.sh.sha256 &&
sha256sum --check install-guide.sh.sha256 &&
sudo sh ./install-guide.sh --check
```

必须识别已有 `Current: 1.0.0`；`not installed` 或报错时停止。核对原实例后，再单独运行：

```sh
sudo sh ./install-guide.sh
sudo guide-update --check
```

成功后保存 updater，不重置原密码、不初始化新库。后续使用 `sudo guide-update` 或 `sudo guide-update --check`。

其他服务名、手工启动、wrapper、容器等须先按[旧部署接入与人工迁移](../deployment/INSTALL.md#从-v100-首次接入-updater)处理。检测到可识别的其他 Guide 进程/已加载服务会拒绝首次安装；未运行、未加载、改名的自定义部署不能自动穷举，请勿把未识别误当作全新安装。

## 数据库兼容与备份

schema 保持 **13**。已有 OAuth、Service、分类、图标库、密码 hash 和会话继续使用原数据库；现有 unit 不覆盖。停服且确认进程退出后备份主 DB、当时存在的 WAL/SHM，以及旧 binary；备份保存在各自目录的 `backups/` 下，保护权限且不自动清理。

失败回滚恢复完整快照、原 ownership/权限和旧 binary，不只替换二进制。升级前仍建议保存独立一致性备份；不要复制运行中的 SQLite 主文件作为完整备份。所有备份均可能含凭据，禁止公开。

## 不支持与注意事项

- ARM、Windows、Alpine/musl、Docker/其他容器内升级、OpenRC 不支持；本次没有官方 Docker 镜像。
- 不自动转换其他服务管理方式、猜测数据库路径、覆盖自定义服务或创建第二个实例来“升级”。
- wrapper、相对 DB、变量/specifier、复杂 namespace、符号链接/硬链接和备份名称冲突会拒绝自动升级。
- `--check` 不下载二进制、不自更新、不写锁、不修改服务或 DB；默认更新会短暂停服进行一致性备份。
- SIGKILL、断电或磁盘故障不能保证自动回滚；人工恢复与锁处理见[安装说明](../deployment/INSTALL.md)。
- 正式资产发布/下载链路和重启恢复仍须在相应阶段验证；既有第三方许可证据缺口见[THIRD_PARTY_NOTICES.md](../../THIRD_PARTY_NOTICES.md)。
