## 新增

- 导航页背景加入字符锦鲤池塘（来自开源项目 [ascii-pond](https://github.com/stqfdyr/ascii-pond)）：用字符拼成的锦鲤在页面背后游动，鼠标移过去鱼会游过来，点一下空白处会撒鱼食。
  - 鱼从卡片底下穿过，只在卡片之间的空隙和页面两侧露出来；游到分类栏、状态行等文字下面时会自动变淡，不挡阅读。
  - 颜色跟随页面的浅色、深色主题一起切换。
  - 系统开了「减弱动态效果」时鱼会游得很慢；高对比度模式下不显示池塘。

## 改进

- 后台「导航外观」里的「页脚动画」开关改为「背景动画」，控制的是新的锦鲤池塘，切换后立即生效。
- 页脚打着手电找东西的小人动画已移除，页脚只保留 GitHub 源码链接。

## 升级说明

- 以前在后台关掉过「页脚动画」的站点，升级后背景动画也保持关闭，不会突然出现动画；在后台打开「背景动画」即可启用。没改过这个开关的站点默认开启。

## 升级方式

先看完上面的内容，决定更新的话，在服务器终端运行：

```bash
sudo guide-update
```

更新前会自动备份数据库，失败会自动回滚。只想确认版本、不更新：

```bash
sudo guide-update --check
```
