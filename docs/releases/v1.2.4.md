## 新增

- **私有模式**：后台「设置」里的开关（原来叫「开放公开状态页」）。开启后，没登录的人打开导航页会直接被带到登录页，看不到页面和任何网站；登录后自动回到导航页。登录后的跳回地址只认站内首页，不能被利用跳到别的网站。
- **版本更新预览**：后台「设置 → 版本更新」显示当前版本和最新版本，可以直接打开对应的 GitHub Release 查看更新内容，并给出更新命令。有新版本时，后台顶栏会出现「新版本」按钮。后台只做检查和提示，不会自己更新，要不要更新由你在服务器终端决定。

## 改进

- 「开放公开状态页」开关改名为「私有模式」，开关方向随之反过来。已有的设置原样保留，不需要重新配置。
- 每个版本的 Release 页面开头都会写明这一版新增、改进和修复了什么。

## 修复

- 私有模式下，没登录的访客打开导航页时，之前只看到「加载失败：需要登录后查看」，没有登录入口。现在会直接带到登录页。

## 升级方式

先看完上面的内容，决定更新的话，在服务器终端运行：

```bash
sudo guide-update
```

更新前会自动备份数据库，失败会自动回滚。只想确认版本、不更新：

```bash
sudo guide-update --check
```
