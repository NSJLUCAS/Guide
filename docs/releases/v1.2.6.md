## 新增

- **分类批量操作**：后台「分类」页每个分类多了一个批量操作按钮，可以对这个分类下的全部网站一次完成：
  - **全部设为公开 / 全部设为私有**：已经是目标状态的网站不会重复修改。
  - **更新图标**：默认只补全还没有图标的网站；也可以选择全部重新获取，用网站提供的第一个图标替换现有图标（包括手动选的）。网站没有提供图标时保留原图标。
  - 处理过程中显示进度，完成后列出哪些网站没处理成功以及原因。

## 改进

- 获取网站图标和网页标题的时限从 5 秒放宽到 10 秒，候选图标的检查改为同时进行，较慢的网站也更容易读取成功。
- 读取网站时以更通用的方式标明身份（浏览器风格的 User-Agent，并声明需要网页内容），一些拒绝陌生客户端的网站也能正常读取。

## 修复

- 网站前面有 Cloudflare 等 CDN 或反向代理时，获取图标失败只会提示「hub 没有正常响应（HTTP 504）」，看不到真正原因。现在会直接显示原因，例如「读取网站超过 10 秒」或「无法读取网站页面」。

## 升级方式

先看完上面的内容，决定更新的话，在服务器终端运行：

```bash
sudo guide-update
```

更新前会自动备份数据库，失败会自动回滚。只想确认版本、不更新：

```bash
sudo guide-update --check
```
