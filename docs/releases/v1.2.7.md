## 改进

- 网站开了 Cloudflare 等人机验证（打开时先显示「请稍候…」）时，获取图标也能给出网站根目录的 `favicon.ico` 作为候选，和浏览器标签页显示 LOGO 的方式一样。网页返回的不是 HTML、超过 1 MiB 或重定向超过 3 次时同样如此。
  - 验证页本身的内容不会被采用：「请稍候…」不会被当成网站名称，批量粘贴时这类网站的名称用域名代替。
  - `favicon.ico` 是候选地址，能否显示以预览为准；网站根目录没有这个文件时，会显示默认图标。

## 升级方式

先看完上面的内容，决定更新的话，在服务器终端运行：

```bash
sudo guide-update
```

更新前会自动备份数据库，失败会自动回滚。只想确认版本、不更新：

```bash
sudo guide-update --check
```
