## 新增

- **批量粘贴网站**：后台「服务」页新增「批量粘贴」按钮。在浏览器里复制多个标签页的网址，粘贴进来就能一次添加多个网站，每行一个网址。也可以在服务页直接按 Ctrl+V，剪贴板里全是网址时会自动打开批量粘贴窗口；在搜索框等输入框里粘贴不受影响。
  - 名称自动使用网页标题；网页读取不到或没有标题时用域名，添加前都可以修改。
  - 图标自动选用网站提供的第一个图标；读取不到时留空，之后可以在编辑里补上。
  - 分类可以每个网站单独选，也可以「全部设为」同一个分类；公开和在线检测对这一批统一设置。
  - 已经添加过的网址会标出「已存在」并自动跳过；不是网址的行会单独列出，不会被悄悄丢掉。
  - 某个网站添加失败时，只有它留在窗口里显示原因，其他网站照常添加。

## 改进

- 后台「获取网站图标」现在会同时读出网页标题，供批量粘贴自动填写名称。

## 升级方式

先看完上面的内容，决定更新的话，在服务器终端运行：

```bash
sudo guide-update
```

更新前会自动备份数据库，失败会自动回滚。只想确认版本、不更新：

```bash
sudo guide-update --check
```
